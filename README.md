# 山林所得税計算Excel

山林の売却などによって得られる山林所得の税額を計算するためのExcelファイルです。

## 概要

山林所得の収入金額や必要経費、特別控除などを入力し、課税山林所得金額および所得税額を試算します。

## 主な機能

* 山林所得の計算
* 必要経費の反映
* 特別控除（最大50万円）の反映
* 課税山林所得金額の計算
* 所得税額の試算
* 税額の1,000円未満切り捨て

## 使い方

1. Excelファイルをダウンロードします。
2. 収入金額や必要経費などの必要な項目を入力します。
3. 計算結果を確認します。

## ダウンロード

[山林所得の計算のしかたExcel](./山林所得の計算のしかたexcel.xlsx)

## 注意事項

* 本Excelは山林所得にかかる税額を試算するためのものです。
* 計算結果は参考情報であり、税額を保証するものではありません。
* 実際の申告では、最新の税法や国税庁の情報を確認してください。
* 個別の事情によって計算方法が異なる場合があります。
